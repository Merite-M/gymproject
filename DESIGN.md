# PolyFit Brand & Design System

A machine-readable visual constitution for PolyFit corporate wellness network.

## Brand Principles
- Corporate-grade + energetic + trustworthy + African-market-ready.
- Deep navy (#0B1F33) + PolyFit electric green (#28D17C) identity.
- Clean white (#FFFFFF) cards with 14px radius and 1px hairlines.
- 10px radius buttons.
- Inter typography with 4px baseline spacing.
- Core visual motif: connected network and benefit flow.
